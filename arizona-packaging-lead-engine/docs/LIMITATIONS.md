# Limitations

Google Apps Script quotas and website restrictions limit throughput. The system cannot guarantee 500 verified contacts, mailbox existence, phone activation, complete Arizona coverage, or LinkedIn access. `FORMAT_VALID` and `MX_PRESENT` are not mailbox verification; `SOURCE_LISTED` is not `PROVIDER_VERIFIED`. A real pilot requires an approved source CSV and user review; no real-world validation is claimed by this repository.
